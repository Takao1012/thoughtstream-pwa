Craft API 設定
API URLとドキュメントIDを設定してください。設定が完了するまでメモを投稿できません。
Craft API URL
Craft → Settings → Imagine タブ → API connection で発行したURL
API キー
Craft → Settings → Imagine タブ → API connection → APIキーを作成
Inbox ドキュメントID
CraftでInboxドキュメントを開いて URL から取得。
例: https://docs.craft.do/editor/d/スペースID/ドキュメントID
メモの保存形式
[2026-06-10 14:32] メモ本文 #タグ

日時は自動付与。タグはスペースまたはカンマ区切りで複数入力可。
